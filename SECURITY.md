# Security policy

This repository contains built, public files only (the engine and baked assets that power https://nomadiichorse.com). It holds no secrets, credentials or personal data.

If you find a security problem on https://nomadiichorse.com or in these files, please write to us through https://nomadiichorse.com/contact-us and mention security in the message. We reply by email, usually within a day. Please do not publish details until we have fixed the issue.
